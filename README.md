# AI-Powered WordPress Content Automation

An AI-powered content automation workflow built with n8n, AI and WordPress REST API.

This project demonstrates how content research, AI content generation, image generation and WordPress publishing can be connected into an automated workflow.

## 🚀 Workflow

User Input
↓
AI Research
↓
Content Structure
↓
AI Content Generation
↓
Content Processing
↓
WordPress
↓
AI Featured Image
↓
WordPress Media Upload
↓
Set Featured Image
↓
Draft / Publish

## ✨ Features

- Automated content workflow

- WordPress media upload
- Featured image automation
- Modular workflow design

## 🎯 Goal

The goal of this project is to reduce repetitive content management tasks by connecting AI, automation and WordPress into a single workflow.
